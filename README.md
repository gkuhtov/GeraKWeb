## 🧭 О проекте

**GeraKStore Web** — веб-интерфейс каталога GeraKStore. Он предоставляет отдельную страницу для просмотра приложений, поиска по каталогу и перехода к доступным материалам.

## ✨ Возможности интерфейса

- 🔎 Поиск приложений.
- 📂 Просмотр категорий и карточек каталога.
- 🔄 Отображение доступных сведений об обновлениях.
- 📱 Адаптация интерфейса для телефона и компьютера.
- 🎬 Визуальный главный экран и дополнительные медиа.
- 🔗 Переходы к связанным разделам и ресурсам.

Набор отображаемых приложений зависит от данных каталога и текущей реализации интерфейса.

## 🧱 Структура проекта

| Путь | Назначение |
|---|---|
| `index.html` | Главная страница |
| `assets/css/gerastore.css` | Основные стили |
| `assets/js/gerastore.js` | Логика веб-интерфейса |
| `assets/images/` | Изображения и графические материалы |
| `assets/video/` | Видеоматериалы |
| `data/apps.json` | Данные приложений для веб-интерфейса |
| `.github/workflows/` | Автоматизация обновления проекта |

Файлы с суффиксами вроде `.bak`, `.before-...` и `.broken` могут быть сохранёнными копиями или экспериментальными вариантами. Не удаляйте их без отдельной проверки.
